# 🧠 MindBloom - Mental Health AI App 🌿

🏆 1st Rank Winner - College Project Exhibition

## 📱 About the App
MindBloom is an AI-powered mental health Android app designed to improve emotional wellbeing.  
It includes mood tracking, meditation sessions, AI voice assistant, and gamified wellness features.

## ✨ Features
- 🤖 AI Voice Assistant (Hindi + English)
- 😊 Mood Tracking System
- 🧘 Meditation & Relaxation Sessions
- 🌿 Gamified Wellness (streaks, progress)
- 📊 User Activity Tracking
- 🔐 Secure Authentication

## 🛠 Tech Stack
- Kotlin (Jetpack Compose)
- MVVM Architecture
- Firebase / API Integration
- Retrofit

- 🥇 Secured 1st Rank in College Project Exhibition
